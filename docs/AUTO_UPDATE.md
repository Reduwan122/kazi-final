# 🚀 কাজী এগ্রোটেক সম্পূর্ণ স্বয়ংক্রিয় আপডেট ও রিলিজ সিস্টেম (Automated In-App Update & Release System)

এই ডকুমেন্টে কাজী এগ্রোটেক (Kazi Agrotech) অ্যাপ্লিকেশনের সম্পূর্ণ স্বয়ংক্রিয় অ্যান্ড্রয়েড রিলিজ এবং ইন-অ্যাপ আপডেট সিস্টেমের বিস্তারিত আর্কিটেকচার, এককালীন সেটআপ নির্দেশিকা এবং ব্যবহারবিধি লিপিবদ্ধ করা হলো।

---

## ১. সিস্টেমটি কীভাবে কাজ করে (How the System Works)

এককালীন সেটআপ সম্পন্ন হওয়ার পর ডেভেলপারকে আর কখনোই ম্যানুয়ালি:
- `versionCode` বা `versionName` পরিবর্তন করতে হবে না
- লোকালি রিলিজ APK বিল্ড বা সাইন করতে হবে না
- গিটহাবে ট্যাগ বা রিলিজ তৈরি করতে হবে না
- SHA-256 হ্যাশ গণনা বা কপি-পেস্ট করতে হবে না
- ফায়ারবেস ডাটাবেসে ম্যানুয়ালি তথ্য আপডেট করতে হবে না

### 🔄 সম্পূর্ণ স্বয়ংক্রিয় লাইফসাইকেল (End-to-End Automated Workflow):

```
ডেভেলপার কোড পরিবর্তন করেন
        ↓
git add .
        ↓
git commit -m "নতুন ফিচার ও উন্নতি"
        ↓
git push origin main
        ↓
GitHub Actions স্বয়ংক্রিয়ভাবে শুরু হয় (release.yml)
        ↓
সর্বশেষ প্রোডাকশন রিলিজ ট্যাগ চেক করে পরবর্তী সংস্করণ গণনা করে (১ → ২ → ৩...)
        ↓
Gradle বিল্ডে স্বয়ংক্রিয়ভাবে versionCode ও versionName ইনজেক্ট করে
        ↓
সিক্রেট থেকে প্রোডাকশন সাইনিং কী রিস্টোর করে
        ↓
ক্লিন প্রোডাকশন রিলিজ APK বিল্ড ও সাইন করে
        ↓
APK ভ্যালিডেশন এবং SHA-256 হ্যাশ জেনারেট করে
        ↓
গিটহাব রিলিজ (GitHub Release) তৈরি করে APK আপলোড করে
        ↓
ডাইরেক্ট ডাউনলোড লিঙ্ক তৈরি করে ফায়ারবেস রিয়েলটাইম ডাটাবেস (appUpdate) আপডেট করে
        ↓
ব্যবহারকারীর মোবাইলে ইনস্টল থাকা অ্যাপ ফায়ারবেস থেকে আপডেট শনাক্ত করে
        ↓
আধুনিক বাংলা আপডেট ডায়ালগ প্রদর্শন করে
        ↓
সরাসরি গিটহাব থেকে স্ট্রিমিং HTTPS ডাউনলোড করে SHA-256 ভেরিফাই করে
        ↓
অ্যান্ড্রয়েড প্যাকেজ ইনস্টলার চালু করে ডেটা অক্ষত রেখে অ্যাপ আপডেট সম্পন্ন করে!
```

## ২. ফায়ারবেস রিয়েলটাইম ডাটাবেস স্ট্রাকচার (Firebase Realtime Database Structure)

ফায়ারবেস রিয়েলটাইম ডাটাবেসে `appUpdate` নোডের মাধ্যমে মেটাডাটা সংরক্ষিত হয়:

```json
{
  "appUpdate": {
    "versionCode": 2,
    "versionName": "1.0.2",
    "apkUrl": "https://github.com/Reduwan122/kazi-update-v2/releases/download/v1.0.2/kazi-agrotech-1.0.2.apk",
    "forceUpdate": false,
    "title": "নতুন আপডেট পাওয়া গেছে",
    "message": "কাজী এগ্রোটেক সংস্করণ v1.0.2 ব্যবহারের জন্য প্রস্তুত।",
    "releaseNotes": "* ড্যাশবোর্ড লোডিং গতি বৃদ্ধি\n* ডিমের হিসাব সমন্বয়",
    "fileSize": 18456210,
    "sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
    "releaseDate": "2026-08-27"
  }
}
```

## ৩. ফায়ারবেস সিকিউরিটি রুলস (Firebase Security Rules)

`appUpdate` নোডটি যাতে সাধারণ ব্যবহারকারীরা পরিবর্তন করতে না পারে এবং শুধুমাত্র সার্ভিস একাউন্ট (GitHub Actions) লিখতে পারে, সেজন্য ফায়ারবেস রুলস নিচের মতো সেট করুন:

```json
{
  "rules": {
    ".read": "auth != null",
    ".write": "auth != null",
    "appUpdate": {
      ".read": true,
      ".write": false
    }
  }
}
```
*(দ্রষ্টব্য: GitHub Actions-এর সার্ভিস একাউন্ট অ্যাডমিন প্রিভিলেজ দিয়ে রুলস বাইপাস করে সুরক্ষিতভাবে `appUpdate` আপডেট করে।)*

## ৪. এককালীন গিটহাব সিক্রেটস কনফিগারেশন (One-Time GitHub Secrets Setup)

GitHub রিপোজিটরির **Settings** ➔ **Secrets and variables** ➔ **Actions** ➔ **New repository secret**-এ নিচের সিক্রেটগুলো যোগ করুন:

| সিক্রেটের নাম | বিবরণ | উদাহরণ |
| :--- | :--- | :--- |
| `KEYSTORE_BASE64` | প্রোডাকশন রিলিজ সাইনিং কীস্টোর ফাইলের Base64 এনকোডেড স্ট্রিং | `MIID...` |
| `KEYSTORE_PASSWORD` | কীস্টোরের মূল পাসওয়ার্ড | `your_keystore_password` |
| `KEY_ALIAS` | কী-এর অ্যালিয়াস নাম | `upload` বা `key0` |
| `KEY_PASSWORD` | কী-এর পাসওয়ার্ড | `your_key_password` |
| `FIREBASE_SERVICE_ACCOUNT` | ফায়ারবেস সার্ভিস একাউন্টের সম্পূর্ণ JSON ফাইল কনটেন্ট | `{"type": "service_account", ...}` |

---

### ক. কীস্টোরকে Base64 করার নিয়ম (How to get KEYSTORE_BASE64):
উইন্ডোজ পাওয়ারশেলে (PowerShell):
```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("my-upload-key.jks")) | Set-Clipboard
```
অথবা লিনাক্স/ম্যাকে:
```bash
base64 -w 0 my-upload-key.jks | pbcopy
```
ক্লিপবোর্ডে কপি হওয়া সম্পূর্ণ স্ট্রিংটি GitHub Secret-এ `KEYSTORE_BASE64` হিসেবে পেস্ট করুন।

---

### খ. ফায়ারবেস সার্ভিস একাউন্ট তৈরি ও কালেকশন (Firebase Service Account Setup):
1. **Firebase Console** (https://console.firebase.google.com)-এ যান।
2. প্রজেক্ট সেটিংসে (**Project Settings ⚙️**) ক্লিক করুন।
3. **Service accounts** ট্যাবে যান।
4. **Generate new private key** বাটনে ক্লিক করে JSON ফাইলটি ডাউনলোড করুন।
5. ডাউনলোড করা JSON ফাইলটির সম্পূর্ণ টেক্সট কপি করে GitHub Secret-এ `FIREBASE_SERVICE_ACCOUNT` নামে সেভ করুন।

## ৫. ⚠️ অত্যন্ত গুরুত্বপূর্ণ: প্রোডাকশন সাইনিং কী ব্যাকআপ (Keystore Backup Warning)

> [!CAUTION]
> **প্রোডাকশন কীস্টোর ফাইলটি অত্যন্ত সংবেদনশীল ও গুরুত্বপূর্ণ!**
> অ্যান্ড্রয়েডে একবার একটি নির্দিষ্ট সাইনিং সার্টিফিকেট দিয়ে অ্যাপ ইনস্টল করা হলে, পরবর্তী সকল আপডেট APK অবশ্যই একই সাইনিং কী দিয়ে সাইন করতে হবে। সাইনিং কী পরিবর্তন হলে পুরোনো ডেটা অক্ষত রেখে অ্যাপ আপডেট করা সম্ভব হয় না।
> তাই মূল কীস্টোর ফাইলটি গিটহাবের বাইরে গুগল ড্রাইভ বা সুরক্ষিত অফলাইন স্টোরেজে নিরাপদে ব্যাকআপ রাখুন।

## ৬. স্বয়ংক্রিয় ভার্সন গণনা পদ্ধতি (Automatic Versioning Logic)

- প্রথম রিলিজের ক্ষেত্রে (যদি কোনো রিলিজ না থাকে):
  - `versionCode = 1`
  - `versionName = "1.0.1"`
- পরবর্তী রিলিজের ক্ষেত্রে:
  - পূর্ববর্তী সফল রিলিজের `versionCode` + `1`
  - উদাহরণ: `v1.0.7` এর পর পরবর্তী রিলিজ হবে `v1.0.8` (`versionCode: 8`)
- ভার্সন সবসময় ঊর্ধ্বগামী (Strictly monotonically increasing: 1 → 2 → 3 → ...)।

## ৭. অ্যাপের আপডেট ফিচার ও আর্কিটেকচার (In-App Features)

1. **ব্যাকগ্রাউন্ড অটো-চেক (Automatic Check):**
   - ড্যাশবোর্ড ওপেন হওয়ার পর অ্যাপ শান্তভাবে ব্যাকগ্রাউন্ডে ফায়ারবেস চেক করে।
   - অতিরিক্ত রিকোয়েস্ট রোধ করতে ৬ ঘণ্টার কুলডাউন (Cooldown) প্রয়োগ করা আছে।
2. **ম্যানুয়াল আপডেট চেক (Manual Check):**
   - **সেটিংস ➔ অ্যাপ সংস্করণ ও আপডেট**-এ ট্যাপ করলেই তৎক্ষণাৎ কুলডাউন বাইপাস করে লাইভ আপডেট চেক হয়।
3. **নিরাপদ SHA-256 ভেরিফিকেশন:**
   - গিটহাব থেকে APK ডাউনলোড শেষ হওয়ার সাথে সাথে ডিভাইসে লোকাল SHA-256 হ্যাশ গণনা করে ফায়ারবেসের হ্যাশের সাথে ১০০% ম্যাচ করা হয়। অমিল হলে করাপ্টেড ফাইল স্বয়ংক্রিয়ভাবে মুছে ফেলা হয়।
4. **Android Package Installer ও FileProvider:**
   - অ্যান্ড্রয়েড ৮ থেকে ১৫+ পর্যন্ত সুরক্ষিত `content://` URI দিয়ে প্যাকেজ ইনস্টলার চালু হয়।
5. **বাধ্যতামূলক আপডেট সমর্থন (Force Update):**
   - কোনো রিলিজ অত্যন্ত জরুরি হলে ফায়ারবেসে `forceUpdate: true` সেট করলে ব্যবহারকারী আপডেট না করে অ্যাপ ব্যবহার করতে পারবেন না।

## ৮. আপনার স্বাভাবিক দৈনিক কাজের নিয়ম (Daily Normal Workflow)

এককালীন সেটআপ শেষ! এখন থেকে অ্যাপ আপডেট করার জন্য আপনাকে শুধু এই তিনটি কমান্ড চালাতে হবে:

```bash
git add .
git commit -m "আপনার পরিবর্তনের বিবরণ লিখুন"
git push origin main
```

বাকি সবকিছু GitHub Actions, GitHub Releases এবং Firebase সম্পূর্ণ নিখুঁতভাবে পরিচালনা করবে।
